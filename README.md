## About

This is the source repository for my personal security blog. I write about web and mobile application security, offensive techniques, AI security, and learning roadmaps for people getting into the field.

Built with [Jekyll](https://jekyllrb.com/) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme. Hosted on GitHub Pages.

## About Me

I'm Youssef, a penetration tester based in Cairo. I got into security before my university noticed — Scientific Computing at Ain Shams, if you're asking — and never really looked back.

Since then: led security teams, built CTF challenges from the ground up, taught hundreds of people how to break web and mobile applications. My current obsession is cross-platform mobile security and closing the gap between how security gets taught and how it actually gets done on a real engagement.
